การใช้งานระบบ

หากไม่สามารถเข้าสู่ระบบ บันทึกอัลบั้ม หรืออัปโหลดรูปภาพได้ ให้ติดต่อผู้ดูแลระบบพร้อมแจ้งข้อความผิดพลาดที่ปรากฏ

อย่าส่งรหัสผ่าน Firebase หรือ ImgBB API Key ให้บุคคลอื่น และอย่าใส่ Secret ลงในไฟล์ HTML

ข้อมูลติดต่อ

ข้อมูลติดต่อส่วนนี้เก็บเฉพาะในเบราว์เซอร์ ไม่ใช่การตั้งค่ากลางของระบบ
